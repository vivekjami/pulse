# Handle ELO Points Settled calls

ELO starts at 1000 and moves against a fixed 1200 house with K=32, so a correct call as an underdog gains more than a wrong one costs. Points come from Call the Surge: a stake is deducted when placed and returned doubled only if the detector confirms the burst after you called it.
